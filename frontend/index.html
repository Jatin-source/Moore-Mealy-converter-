Automata Theory & Viva Defense Guide

1. Formal Automata 6-Tuple Definitions

M = (Q, Σ, Δ, δ, λ, q₀)

  • Q: Finite set of states
  • Σ: Input alphabet
  • Δ: Output alphabet
  • δ: State transition function $Q \times \Sigma \to Q$
  • Moore λ: State output function $Q \to \Delta$ (output depends only on state)
  • Mealy λ: Transition output function $Q \times \Sigma \to \Delta$ (output depends on state & input symbol)
  • q₀: Initial start state

2. The Headline Edge Case: State Splitting

In a Mealy machine, different transitions entering the same state $q$ can carry different outputs (e.g. $q_0 \xrightarrow{0/0} q_1$ and $q_2 \xrightarrow{1/1} q_1$). Because a Moore state can only have one single output, $q_1$ cannot be both '0' and '1'. Therefore, $q_1$ must split into distinct states: q1_0 and q1_1. Outgoing transitions from $q_1$ are duplicated for both split states!

3. The Output Alignment Convention

For an input string of length $n$:

  • Moore output length: $n + 1$ (emits initial state output at $q_0$ before any symbol is consumed).
  • Mealy output length: $n$ (emits outputs only upon taking transitions).

Convention: In aligned equivalence verification, the Moore machine's leading output symbol at $q_0$ is treated as a pre-input response and excluded from comparison, resulting in exact 1:1 match with Mealy.

4. Top Viva Examination Questions & Answers

Q: Why does Moore → Mealy preserve the state count?

A: Because each Moore state has a fixed output, we can simply place that output onto all transitions entering that state. No states need to be split or duplicated.

Q: What is the upper bound on states when converting Mealy → Moore?

A: At most $|Q_{Mealy}| \times |\Delta|$. In the worst case, every Mealy state is reached by all possible output symbols.

Q: How do you handle a Mealy initial state with no incoming transitions?

A: Our algorithm deterministically assigns the default output (the first symbol in the output alphabet) to ensure the Moore initial state is well-defined.
